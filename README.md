# Artifex Fit

Личное приложение для тренировок по программе «Тяжёлые тренировки: 4 недели + разгрузка».
Показывает тренировку на сегодня, сам считает веса по правилам программы, записывает подходы с таймером отдыха и рисует прогресс.

**Открыть:** https://artifex141.github.io/artifex-fit/

## Установка на iPhone

1. Открой ссылку в **Safari**.
2. Нажми «Поделиться» → **«На экран „Домой“»**.
3. Запускай с иконки — приложение работает без интернета.

## Данные

- Всё хранится только на телефоне (IndexedDB), никуда не отправляется.
- Делай резервную копию: **Профиль → Экспорт** → «Сохранить в Файлы» (iCloud). Восстановление — **Импорт**.
- Если удалить приложение с экрана «Домой» или очистить данные Safari, записи пропадут — без копии их не вернуть.

## Как приложение считает веса

- **Н1** — вес, с которым сделано большинство подходов на неделе 1. Если неделя 1 не записана — берётся неделя 2, иначе «Стартовые веса» в профиле.
- **Н3 / Н4** — то же для недель 3 и 4.
- Если на прошлой неделе в подходе на 2+ повторения меньше плана — вес не повышается (с подсказкой).
- Разгрузка: 72,5% от Н4 с округлением (гантели — 2,5 lb, остальное — 5 lb).
- В конце цикла приложение спросит, с каких весов начать следующий.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173/artifex-fit/
npm test         # тесты логики программы и хранилища
npm run build
```

Логика программы — `src/program/` (чистый TypeScript, покрыт тестами), хранилище — `src/db/`, экраны — `src/ui/`.
Спецификация — `docs/superpowers/specs/`, план — `docs/superpowers/plans/`.
